One Letter for Your Day — a program that writes a single letter, K, standing for the word that describes the day: knackered. The judge picks the letter whose hidden word feels more vivid, funnier or truer, and K is the sharpest initial for a day that left nothing in the tank.

## Run it

```sh
node main.ts
```
